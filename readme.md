# Personal website
I created a personal website with HTML and CSS.

## HTML

### Requirements for the website:

- Layout your HTML with semantic tags

- Navbar with links to sections of your page

- Hyperlink that opens a new window

- Different headings (h1, h2, h3)

- A paragraph with a short bio about you

- An image that represents you

- Footer

- Ordered and unordered list

- Add classes and ids

- Form of your choice

- Table with 4 column titles of
your choice

- Metadata in the <head>

- Check your indentation!


## CSS

### Requirements for styling:

- Have a look at this link of websites for styling ideas!

- Use a nice colour palette for your website, e.g. from Colorhunt

- Style your website using id and class selectors.

- Think about the layout of your page, background colours, font colours, fonts (Google fonts).

- Familiarise yourself with the Box Model and include Margin and Padding to your styling.

- Play around with Flexbox. Use on your nav bar and on your ordered or unordered list, and on any other areas of your website if you want to. View link here for guidance.

- Review CSS Layouts and include a position: fixed;
